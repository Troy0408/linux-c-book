# 离线完整性检查

运行 `make verify`。检查基于本仓库中 `manifest/source.json` 及保存的 HTML 快照，不访问网络。该快照有 219 个页面、342 个目录项；核对了页面与资源 SHA-256、目录项顺序及其实际 TeX 目标、页面映射及锚点。

脚本对照原始 HTML 和转换清单，核对 124 个二级节、64 个无编号小节、137 个图、48 个表、96 个示例、31 条参考文献和 628 条索引；核对图表及示例在 TeX 中的标题命令数量、142 种插图的引用次数和目标文件。1075 个 `programlisting`/`screen` 块逐块与原始文本字节比较，并检查输出引用。脚注在网页 DOM 中位于页末而转换时回到正文位置，因此代码按页面、类型和内容的多重集核对。

前言将标题和全部正文按原顺序拼接，去掉 HTML 与 TeX 引入的空白后逐字比较；排版命令、地址包装及链接命令会还原为可见文字，未知命令会报错。此项检查覆盖短片段、行内代码、强调和链接可见文字，但不核对空白差异、排版、段落边界或链接目标。GFDL 附录检查了 88 个非空原文行的内容和顺序。自动检查不能证明图片视觉内容或全书其他普通正文逐字一致，图表标题的具体内容也未做逐字比较。

源站快照本身有三项 CSS 图片引用返回 404：`images/note.png`、`images/tip.png` 和 `images/warning.png`；书中插图均已保存。原站还有部分跨页链接指向目标页不存在的片段，详见 `link-check.json`；转换中的修复记录在 `conversion.json` 的 `repaired_source_links`。
